# Next Portfolio

This project is **not complete**. Development was stopped in favor of starting a new portfolio built with **Three.js** and **GSAP**.

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- GSAP (animations & ScrollTrigger)
- i18n (English / Russian)

## What Was Built

- Home page with GSAP entry animation, animated hero with profile circle, gradient ring, floating bubbles
- About page with skills, experience timeline, education
- Projects page with card grid
- Blog page with featured/regular post layouts
- Contact page with form and availability status
- Dark/light theme toggle
- Animation toggle
- Language switcher (EN/RU)
- Scroll-triggered reveal animations across all pages

## Why Stopped

Decided to rebuild the portfolio from scratch using **Three.js** for 3D visuals and **GSAP** for advanced animations, aiming for a more immersive and interactive experience.
